# LightOFF

Застосунок у треї для Windows, що перемикає EcoFlow STREAM між батареєю і
мережею за графіком відключень Вінницяобленерго (ВОЕ).

Rust і Tauri 2, інтерфейс на Svelte 5. Інтерфейс українською.

## Що тут варто пояснити

### Перемикання, для якого в пристрою немає команди

У STREAM немає команди «живити дім від батареї зараз». LightOFF досягає того
самого через резерв живлення (`cfgBackupReverseSoc`) у режимі Self-powered:

| Режим | Який резерв записується | Що відбувається |
|---|---|---|
| Від станції | ліміт розряду + 3 % (типово 13 %) або своє число | батарея покриває споживання дому |
| Від мережі | поточний заряд, округлений угору, або своє число | батарея тримає заряд, дім живиться з мережі |

Пристрій не приймає резерв менший за «ліміт розряду + 3 %», тому кожне
значення обмежується цим числом знизу і лімітом заряду згори. Якщо пристрій не
в режимі Self-powered, LightOFF спершу вмикає його. STREAM реагує на зміну
приблизно за 1–2 хвилини.

### Відключення плануються блоками по дві години

ВОЕ може оголосити відключення на чотири чи шість годин, а вимкнути лише одну
двогодинну частину. Тому кожне вікно відключення ділиться на блоки (типово по
дві години), і кожен блок отримує свою пару перемикань:

- за 5 хв до початку блоку — «від станції» і сповіщення Windows;
- через 15 хв після початку блоку — назад «від мережі».

Дві години — одна пара, чотири — дві, шість — три. Вікно, що переходить через
північ, вважається одним вікном. Усі три числа змінюються в «Налаштуваннях», а
клітинки «можливе відключення» можна рахувати як відключення або пропускати.

Дія виконується, навіть якщо запізнилася до 10 хвилин (сон, перезапуск, збій
мережі); невдалу дію повторює не частіше разу на хвилину. Уже виконані дії
пам'ятаються між перезапусками.

### Сайт за перевіркою на бота

`disconnection.voe.com.ua` стоїть за перевіркою Cloudflare, тому LightOFF не
тягне його через HTTP. Він відкриває сайт у власному вікні WebView2, як
відкрила б людина. Вбудований скрипт (`voe.js`) шукає збережену адресу через
пошук самого сайту й зчитує таблицю графіка. Якщо сайт просить перевірку
«я не робот» — її проходите ви у цьому вікні.

Сторінка не має доступу до застосунку. Щоб передати результат, скрипт
переходить на `https://lightoff.invalid/<тип>#<json>`; застосунок скасовує цей
перехід і читає дані з адреси.

Фонове оновлення (типово щогодини) іде в прихованому вікні. Якщо сайт хоче
перевірку або пошук адреси не вдався, приховане вікно закривається, а ви
отримуєте сповіщення оновити графік з екрана «Графік».

## Що робить

- **Стан STREAM**: заряд, резерв, потужність батареї, дому, мережі й сонця
- **Перемикання вручну**: «від станції», «від мережі», свій резерв або
  повернення AI Mode — у вікні або з меню трею
- **Графік ВОЕ** із сайту, як описано вище
- **Графік вручну**: клітинки по пів години на сьогодні й завтра — клацнути
  або протягнути пензлем «Відключення», «Можливе» чи «Світло є»
- **Автоматика** за графіком, вмикається у вікні або в треї
- **Журнал** усіх дій, світла й темна тема
- **Підказка в треї**: заряд, поточне джерело і наступне заплановане перемикання

Закриття вікна ховає його в трей; автоматика працює, доки ви не оберете
**Вийти** в меню трею.

## З чим з'єднується

- **EcoFlow IoT Open Platform** (типово `api-e.ecoflow.com`; у «Налаштуваннях»
  можна обрати `api.ecoflow.com` чи `api-a.ecoflow.com`). Запити підписуються
  HMAC-SHA256. Стан зчитується кожні 20 секунд, коли вікно відкрите, і кожні
  60 секунд, коли сховане. Поки не введено ключі й серійний номер, нічого не
  надсилається.
- **disconnection.voe.com.ua** — у власному вікні браузера застосунку. Фонове
  оновлення працює лише після того, як збережено адресу, і вимикається
  (інтервал 0).

Інших з'єднань немає.

## Ключі й дані

Потрібні **Access Key** і **Secret Key** з платформи розробника EcoFlow та
серійний номер вашого STREAM. Для графіка ВОЕ вказуєте місто, вулицю й будинок.

Усе зберігається в `%APPDATA%\LightOFF\`:

| Файл | Що в ньому |
|---|---|
| `settings.json` | ключі EcoFlow, серійний номер, адреса, параметри автоматики — **відкритим текстом** |
| `schedule.json` | графік |
| `state.json` | чи увімкнена автоматика і які перемикання вже виконано |
| `journal.jsonl` | журнал |
| `logs\` | технічні логи, зберігаються 7 днів |

Ключі зі старої Python-версії LightOFF можна імпортувати з її `config.json`
у «Налаштуваннях».

## Автозапуск

Типово вимкнений. Перемикач **Автозапуск** у «Налаштуваннях» додає значення
`LightOFF` у `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, яке запускає
застосунок згорнутим у трей (`--tray`); вимкнення перемикача його видаляє.

## Збірка

Потрібні Rust (stable), Node.js 22+ і pnpm. Вікно ВОЕ використовує WebView2.

```powershell
pnpm install
pnpm tauri dev                  # розробка з гарячим перезавантаженням інтерфейсу
pnpm tauri build                # інсталятор NSIS: src-tauri\target\release\bundle\nsis\
pnpm check                      # svelte-check
```

Тести логіки — планувальник, підпис запитів EcoFlow, резерви, розбір графіка:

```powershell
cd src-tauri
cargo test
```

Збірки: див. Releases.

```
src/                     інтерфейс (Svelte 5)
  lib/screens/           «Стан», «Графік», «Журнал», «Налаштування»
  lib/components/        кнопки, перемикачі, заголовок вікна
src-tauri/src/
  ecoflow.rs             клієнт EcoFlow API (підпис HMAC-SHA256, стан, резерв)
  planner.rs             графік -> вікна відключень -> блоки -> перемикання
  automation.rs          фонові цикли: стан, виконання перемикань, оновлення графіка
  schedule.rs            модель графіка, збереження, розбір даних сайту
  voe.rs, voe.js         вікно сайту ВОЕ і скрипт, що читає таблицю
  tray.rs                іконка в треї і меню
  autostart.rs           значення в HKCU Run
  settings.rs, state.rs  налаштування, стан застосунку, журнал
```
